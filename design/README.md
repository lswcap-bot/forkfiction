# ForkFiction UI 리디자인 — Claude Code 인계용

지금 사이트(forkfiction.vercel.app)의 **화면 구성은 그대로 두고 스타일만 새로 입히는** 작업이다.
`screens/` 안의 HTML은 디자인 시안이다. 그대로 복사해 넣지 말고, 기존 컴포넌트에 스타일과 구조를 옮겨 적용할 것.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `design-tokens.css` | 색·글꼴·글자 크기·모서리·간격·그림자 CSS 변수. 전역 CSS에 그대로 넣어 쓴다 |
| `screens/*.html` | 화면별 시안 (브라우저로 바로 열림, 화면끼리 링크로 이어짐) |
| `screens/tokens.html` | 토큰을 눈으로 보는 보드 + 빈 상태 디자인 |

글꼴은 Google Fonts에서 불러온다: **IBM Plex Sans KR**(UI·숫자·로고), **Noto Serif KR**(장 본문·작품 제목·장 제목).

## 화면 ↔ 지금 사이트 경로

| 시안 | 경로 (지금 사이트 기준) | 비고 |
|---|---|---|
| `home.html` / `home-mobile.html` | `/` | |
| `works.html` / `works-mobile.html` | `/works` | |
| `work-fork.html` / `work-fork-mobile.html` | `/w/:slug` | 갈래 작품 · 독자 시점 · 목차 탭 |

| `upload.html` / `upload-mobile.html` | 작품 올리기 화면 | 1단계(원고)만 시안 있음 |

## 공통 규칙

### 헤더
- 왼쪽: 텍스트 로고 `Fork`(700) + `Fiction`(400)
- 오른쪽: 전체 목록(책 아이콘) · **작품 올리기**(검은 알약, 연필 아이콘) · 알림 종(44px 원형, 새 알림이면 빨간 점) · 프로필(아바타 + 이름 알약)
- 모바일: 로고 + 44px 원형 아이콘 4개 (목록 · 올리기(검정) · 알림 · 아바타)
- 장 읽기 화면에는 사이트 헤더를 두지 않는다 (뒤로 가기 + 작품명 · 작가 + 글자 크기 조절만)

### 작품 카드 (`.card`)
- 모서리 28px, 안쪽 여백 18px, 최소 높이 210px, 그림자 없음
- **배경색 = 작품 종류**
  - 원작 `--ff-kind-original`
  - 갈래 `--ff-kind-fork`
  - 정사로 인정된 갈래 `--ff-kind-canon` + 검은 "정사" 칩
  - 임시 저장: 흰 바탕 + 1.5px `--ff-kind-draft-line` 테두리 + "임시 저장" 칩 (본인만 보임)
- 위 → 아래 순서
  1. 제목(16px/700)과 오른쪽 위 40px 원형 ⋯ 버튼
  2. 갈래일 때만: 갈래 아이콘 + "『칼의 여행』 8장에서 갈라짐"(12px)
  3. 진행 막대
  4. 막대 아래 캡션 "7장 물려받음 · 4장 새로 씀"
  5. 맨 아래: 아바타 · 필명 · 날짜 · 별 수 · 갈래 수
- **진행 막대**: 장 하나 = 칸 하나(높이 5px, 간격 4px)
  - 물려받은 장 = `--ff-bar-inherited`(진한 칸)
  - 고친 장·새로 쓴 장 = `--ff-bar-new`(연한 칸)
  - 원작은 전부 진한 칸 + "10장 · 연재 중"
- 홈 "요즘 갈래가 많이 나는 원작" 카드에는 "최근 14일 새 갈래 +6" 줄을 추가

### 알약·탭·정렬
- **필터 알약** (높이 44): 흰 바탕 + 테두리, 오른쪽에 개수 배지. 선택되면 검은 바탕 + 노란 배지
- **정렬**: 회색 트랙(`--ff-mute`) 안의 분절 버튼, 선택된 것만 흰 바탕 + `--ff-shadow-1`
- **작품 대문 탭**(목차/갈래 지도): 필터 알약과 같은 모양

### 장 배지 (작품 대문 목차)
- 물려받음: 검은 바탕 흰 글자
- 고침: 흰 바탕 + 1.5px 검은 테두리
- 새 장: 연분홍 바탕

### 광고 자리
`--ff-mute` 바탕, 1px 점선 테두리, 모서리 24px, 가운데에 "광고" 라벨.

| 화면 | 위치 |
|---|---|
| 홈 | 칸 사이 2개 (가운데 정렬, 최대 728px) |
| 전체 목록 | 12번째 카드 뒤 1개 (그리드 전체 폭) |
| 작품 대문 | 목차·지도 끝 1개 |
| 장 읽기 | 본문 끝 1개 + 데스크톱 오른쪽 칸에 스크롤 따라오는 300×600 1개 |

지금 사이트는 읽기 화면 오른쪽 칸에 작은 광고가 여러 개 있는데, 시안에서는 1개로 줄였다. 바꿀지는 사용자 결정이 필요하다.

### 빈 상태
지금 데이터가 적어 대부분의 칸이 비어 있다. `tokens.html` 아래쪽의 빈 상태 상자를 쓴다.
- 점선 테두리, 바탕 `--ff-paper`, 높이 150px 이상
- 문구 + "원작 둘러보기" 같은 보조 버튼

### 장 읽기
- 본문 Noto Serif KR 19px(모바일 17px), 행간 1.95, 최대 폭 38em(한 줄 약 40자), `word-break: keep-all`
- 본문 안 `##` 소제목은 21px/700
- 장 끝 순서
  1. "— N장 끝 —"
  2. 현장 기록 상자(흰 패널)
  3. 목차 · 다음 장 줄
  4. 광고
  5. 연분홍 "여기서 갈라지기" 상자 (태그라인 + 검은 버튼 + "이 장에서 갈라진 갈래 N개")

## 주의
- 시안 속 작품 제목·필명·별/갈래 수·통계 숫자(128 / 342 / 27)·글자 수는 **견본 데이터**다.
  - 실제 값은 DB에서 가져온다.
  - 『칼의 여행』 장 제목 10개만 실제 데이터다.
- 『울라의 길』 본문·소개·현장 기록 문장은 레이아웃 확인용 자리 채움 글이다.
- 필터 순서: 시안은 `전체 · 원작 · 갈래`, 지금 사이트는 `원작 · 갈래 · 전체`이다. 사용자 확인 후 맞출 것.
- 접근성
  - 아이콘만 있는 버튼에는 `aria-label`을 단다.
  - 누를 수 있는 것은 모두 44px 이상으로 한다.
  - 색만으로 구분하지 않도록 정사·임시 저장에는 칩 글자를 함께 쓴다.
